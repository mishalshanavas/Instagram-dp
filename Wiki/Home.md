# Instagram DP documentation

New here? Follow these pages in order. Install Python first; the wizard handles project dependencies and can install GitHub CLI when a supported package manager is available.

1. Install and launch on [Windows](Windows.md), [macOS](macOS.md), or [Linux](Linux.md).
2. Follow [First setup](First-setup.md) to connect accounts and choose photos.
3. Read [Photos](Photos.md) when you want a different collection.
4. Use [Scheduling and timezone](Scheduling.md) to understand when pictures change.
5. Visit [Troubleshooting](Troubleshooting.md) if a step fails.

Also see [Account safety](Account-safety.md) and [Development](Development.md).

Use arrow keys to move, **Enter** to select, and **Ctrl+C** to cancel. Basic terminals use numbered prompts instead.

**Template versus your copy:** `mishalshanavas/Instagram-dp` is the source template. Its Actions are disabled. Setup creates or selects a repository under your account, where the bot runs.
